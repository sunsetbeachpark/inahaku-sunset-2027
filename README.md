# INAHAKU SUNSET 2027

稲泊サンセット2027のイベント紹介LPです。

## 公開ページ
https://sunsetbeachpark.github.io/inahaku-sunset-2027/

## デザイン
2026年10月31日改訂。「海辺のロードトリップ」をテーマに、車中泊・RV泊を主役とした構成へ変更。
生成り・濃紺・サンセットオレンジ、読みやすい日本語の見出し、旅のチケットをイメージした料金案内を使用しています。
モデルコースは昼・夕景・焚き火・夜・翌朝の5場面。スクロールに合わせて写真・背景色・車の進行表示が切り替わり、各場面へ直接移動することもできます。

## 構成
ビルド不要の静的サイト。GitHub Pagesでmainブランチのルートを配信します。

- index.html：イベント紹介、宿泊場所、モデルコース、食事、料金、アクセス、FAQ
- stay-guide.html：予約、車両・設備、施設・送迎、調理等、キャンセル・荒天・返金の案内
- style.css：PC・タブレット・スマートフォン表示、動きを減らす設定、印刷への対応
- script.js：メニュー、場面切り替え、予約準備中・出典ダイアログ、画面下のプラン案内
- assets/：最適化した公式施設写真・制作資料の画像

## 公開前後に更新する項目
予約はまもなく受付開始予定。申込・決済機能はありません。モデルコースは過ごし方の提案です。
予約先・早割期間、連泊料金・食事回数、車両サイズ・電源等の設備条件、施設チケットと夜間送迎の条件、キャンセル・中止・返金の正式規約は、主催者確認後に更新してください。
資料間で条件が異なる項目は、確認が取れるまで未確定として扱います。

メインの宿泊風景は制作過程で作成したイメージ画像です。現地の実写や実際の宿泊配置を示す写真として扱わないでください。
画像・施設情報の参照元はASSET_SOURCES.mdとページ内に記載。各素材の権利は各権利者に帰属します。
