# INAHAKU SUNSET 2027

稲泊サンセット2027のイベント紹介LPです。

## 公開ページ
https://sunsetbeachpark.github.io/inahaku-sunset-2027/

## 構成
ビルド不要の静的サイトです。GitHub Pagesでmainブランチのルートを配信します。

- index.html：体験紹介、1泊2日のモデルコース、食事、料金、アクセス、FAQ
- stay-guide.html：予約・キャンセル・荒天・返金の案内（詳細公開前）
- style.css：PC・スマートフォン表示、動きを減らす設定への対応
- script.js：メニュー、日程タブ、予約案内、出典ダイアログ
- assets/：最適化した公式施設写真・制作資料の画像

予約はまもなく受付開始予定。申込・決済機能はありません。モデルコースは過ごし方の目安で、主催者確定の行程ではありません。

予約先、早割期間、連泊料金・食事回数、施設チケットと夜間送迎の条件は確定後に更新してください。

画像・施設情報の参照元はASSET_SOURCES.mdおよびページ内に記載。各素材の権利は各権利者に帰属します。
