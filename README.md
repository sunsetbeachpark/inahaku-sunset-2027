# INAHAKU SUNSET 2027

稲泊サンセット2027のイベント紹介LPです。

## 公開ページ
https://sunsetbeachpark.github.io/inahaku-sunset-2027/

## 構成
HTML・CSS・JavaScriptのみで動作します。ビルドは不要です。

- `index.html`：イベント紹介・食事・料金・会場案内・FAQ
- `style.css`：PC・スマートフォン向け表示
- `script.js`：予約受付の案内
- `assets/`：提供された広告記事から切り出した画像

## 公開時の状態
予約受付は準備中です。申込・決済機能はありません。早割期間、予約先、連泊料金、運営詳細が確定したら更新してください。

提供された広告記事v12を基に作成しています。画像・ロゴ等の権利は各権利者に帰属します。
